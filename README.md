# Google Colab × Python 業務効率化 Tips

Excel・CSV、ファイル整理、PDF、報告資料、Web情報などの定型業務を、Google Colabで試せる日本語教材です。Pythonの基礎文法を学んだ方を対象にしています。

## 使い方

1. 下表の「Colabで開く」から目的のノートブックを開きます。
2. 各セルを上から順に実行します。練習用データはノートブック内で生成します。
3. 結果を確認し、最後の練習問題で処理を変更してみてください。

`/content/` はColabの一時的な作業領域です。作成したExcelなどをPCに残すには、ノートブック末尾のダウンロードセルを実行してください。Google Driveに自動保存されるわけではありません。

## 補足

- Tips 19・20は練習部分は認証不要です。自分のGoogle Drive・スプレッドシートとの連携は任意で、本人の認証が必要です。
- Tips 21の実行コードはキーワード分類です。生成AIによる意味分類・要約は発展案として説明しています。
- Tips 17・18は外部サイトへアクセスせず、教材に含めたHTMLを使います。実際のWebサイトを扱う際は利用条件を確認してください。
- Excelなどの練習用ファイルと結果はColab上で作成されます。実務データに置き換える際は個人情報や社外秘情報の取り扱いを確認してください。
